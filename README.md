# astrbot-mxbot / 梦汐Bot

Features:

- `签到`
- `签到排行榜`
- `lp`
- `jrrp`

Install:

1. Clone this repo into `AstrBot/data/plugins/astrbot_mxbot`.
2. Restart AstrBot, or reload the plugin from the WebUI.
3. Make sure the bot can read group member lists.

Aliases:

- `签到`: `qd`
- `签到排行榜`: `排行榜`, `qdphb`, `phb`
- `今日老婆`: `lp`, `jrlp`

Notes:

- Data is stored in `astrbot_mxbot/state.json` under the AstrBot plugin data directory.
- Group chat only for the sign-in and wife features.
- Compatible with `aiocqhttp` / NapCatQQ.
