# astrbot-plugin-affection

Features:

- `签到`
- `签到排行榜`
- `lp`

Install:

1. Clone this repo into `AstrBot/data/plugins/astrbot_plugin_affection`.
2. Restart AstrBot, or use the WebUI plugin page to reload the plugin.
3. Make sure the bot has permission to read group member lists.

Notes:

- Data is stored in `astrbot_plugin_affection/state.json` under the AstrBot plugin data directory.
- Group chat only.
- Compatible with `aiocqhttp` / NapCatQQ.
